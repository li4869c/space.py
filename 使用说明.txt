训练卷留白工具 · 使用说明
==========================

【它是干什么的】
把训练卷 PDF 变成「书写版」：每道题后面按题型留好作答空白，直接打印就能在上面写。
原卷不动，输出写在原 PDF 旁边，文件名后面加「-书写版」。

公式不是重打的：按原页的墨迹整块裁剪、1:1 贴到新页，所以积分号、上下标、
分数线和原卷完全一样，打印不会糊也不会变形。


【最简单的用法：双击】
1. 双击 space.py
2. 黑窗口会提示「把 PDF（或文件夹）拖进本窗口，然后回车」
   —— 直接把 PDF 拖进去，路径会自动填上，按回车
3. 等它打印出每道题的留白表，看到「完成：成功 1 / 共 1 份」就好了
4. 按回车关闭窗口

拖文件夹进去也行：会把这个文件夹里所有 PDF 都处理一遍（不含子文件夹）。


【命令行用法】

  python space.py 试卷.pdf                  处理一份
  python space.py D:\数学合集                处理整个文件夹
  python space.py A.pdf B.pdf C.pdf         一次多份
  python space.py D:\数学合集 -r             连子文件夹一起处理

想调空白大小，在后面加参数：

  --space 1.3                 全部留白放大 30%（觉得窄就用这个）
  --space 0.8                 全部缩小 20%
  --blank "17:260,20:400"     只给第 17、20 题指定高度
  --default 150               所有题统一 150 pt
  --grid "10,19"              第 10、19 题的留白区画 5 毫米浅色方格（作图题好用）
  -o 输出.pdf                 指定输出文件名（只处理一份时可用）

  单位换算：28 pt ≈ 1 厘米，200 pt ≈ 7 厘米。

  例：python space.py 综合卷.pdf --space 1.2 --grid "10" --blank "20:400"


【留白是怎么定的】
脚本会看：题面占几行、有没有「证明/求证」、有没有「求/计算」、是不是「作图」、
有几个 (1)(2) 小问。大致是：

  填空、选择        约 100~120 pt（3.5~4 cm）
  计算题            约 120~170 pt（4~6 cm）
  证明题            约 170~230 pt（6~8 cm）
  作图题            约 230 左右（8 cm），配 --grid 变方格纸
  多小问            按小问个数自动放大

算出来的结果会在窗口里逐题列出来，一眼能看出哪题偏窄，再用 --blank 单独补。


【常见问题】

1. 双击后打开的是编辑器，不是黑窗口
   .py 被关联到编辑器了。改用：右键 space.py →「打开方式」→ 选 python.exe；
   或在编辑器里打开后点运行按钮（Run），效果一样。

2. 提示「需要 PyMuPDF」
   脚本会先自动找本机已经装了库的 Python（Anaconda 之类）并在那个解释器里重跑，
   一般不用管。实在找不到会提示你按 y 自动安装，或者手动执行：
       pip install pymupdf

3. 提示「文件正被阅读器占用」
   生成的书写版你正开着。关掉 PDF 阅读器再跑一次。

4. 提示「没识别到题号」
   脚本靠「靠左的 1. 2. 3. 且题号连续」来切题。
   如果卷子题号是「一、二、三」，或者双栏排版，就认不出来。
   告诉我，我按那份卷子的排法改。

5. 打印机设置
   选「实际大小 / 100%」，别选「适合页面」，否则会缩掉一点边。
   双面打印也没问题：书写区跨页时下一页顶部会接着留白，那是正常的续写空间。

技术细节（想改代码时看）：
  · 题号识别：question_lines()，靠左边界聚类 + 题号连续性
  · 留白估算：auto_blank()，想改系数就动那几个常数
  · 排版：整题不拆，书写区可以延续到下一页
  · 边界按墨迹计算，绝不切断字形（公式跨行也不会被切一半）
